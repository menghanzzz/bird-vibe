|---|---|---|---|

- **BioCLIP 显著优于 qwen**（top1：66:23 不一致对，McNemar p=8.5e-06，bootstrap CI [+7.2,+17.2]pp）

- 成本实测：697 次 qwen 调用 = 99.8 万 tokens ≈ 5.60 元（输出占 ~90%）

## 新发现：KB-drift（评测方法学噪声，待办）

隔离 KB 评测期间，自动入库会把新物种写进临时 KB（v1 触发 152 次），
softmax 分母随评测进程缓慢变大 → **同一张图在不同评测时刻的 BioCLIP 分数会漂移**
（实测 c135_游隼 0.347→0.473）。影响限于 ~0.3~0.5 边界区；改进方向：评测前冻结 KB 快照
或在 ingest 时标记跳过打分。暂记为已知噪声。

## 复评记录

- **v2 全量复评**：2026-10-14 启动，348×3 轮，v1 raw 已备份至 `eval_snapshots/eval_raw_v1_full/`
  预期验证：① 阈值 0.40 的混合提升落地 ② prompt v2 能否追平 free ③ 回退次数应从 1 次增至 ~3%

### v2 结果与归因（2026-10-14 完成，欠费中断 13 张已补洞）

| 指标 | v1 | v2 | McNemar | 结论 |
|---|---|---|---|---|
| std top1 | 62.1% | 61.5% | 4:6, p=0.75 | 无变化 |
| std top3 | 75.0% | 77.0% | **9:2, p=0.070** | ✅ prompt v2 方向性有效 |
| bioclip轮 top1 | 74.4% | 71.8% | 4:13, p=0.052 | ⚠️ 见下 |

- **prompt v2 判定有效**：top3 提升 2.0pp（9:2 不一致对），top1 持平——反锚定措辞让更多正确答案进入候选
- **阈值 0.40 的对照被 KB-drift 污染，结果不予采纳**：回退 1→13 次（机制生效），但
  13 张被判低于 0.40 的样本里 v1 时分数本在阈值上（drift 下移所致），v1 单独赢 13 张。
  且离线 risk-curve 预测的 +0.6pp 未复现（实测 -2.6pp）——根因是**评测期入库使 KB 增长，
  越晚评测的照片 softmax 分母越大、分数系统性下移**，与阈值无关
- **评测期入库还抓到高危 bug**：qwen 拒答输出（"无法识别""图像中无可见鸟类"）曾作为新物种
  成功入库 4 次。已修复（main.py 拒答黑名单+前缀拦截），并新增 `BIRD_DISABLE_INGEST=1`
  冻结开关；batch_eval 启动隔离后端时默认冻结
- 待办：**冻结 KB 重跑**（batch_eval 现默认带冻结）才能干净地测出 0.40 vs 0.20 的真实差异，预计 ~5.6 元

### v3 冻结重跑结果（2026-10-14 晚，348×3 轮，0 error，入库 0 次/冻结拦截 276 次）

| 指标 | v1（污染） | v2（污染） | **v3（冻结·冷库）** | v3 暖库（离线扩展标签） |
|---|---|---|---|---|
| std top1/top3 | 62.1/75.0 | 61.5/77.0 | 60.9/75.6 | — |
| free top1/top3 | 62.9/77.3 | 63.8/77.9 | 63.5/77.9 | — |
| bioclip轮 top1/top3 | 74.4/86.5 | 71.8/85.6 | **71.3/79.9** | **78.2/90.5** |

**最终判定**：

1. **prompt v2 无显著效果**（v3 vs v1 top3：9:7，p=0.80；v2 时的"提升"是漂移噪声）。保留 v2 措辞
   （反锚定方向合理、无害），但不再宣称收益。std 整体不如 free 的归因仍未定（地点 vs 日期）。
2. **阈值 0.40 的准确性收益为 0**（冻结数据上 0.20/0.30/0.40 混合 top1 同为 71.3%）；
   保留 0.40 的理由只剩 OOD 安全（拦 8/11 幻觉）。已落地。
3. **v1 的 86.5% 之谜破解**：不是 BioCLIP 变强，是评测期间系统把 7 个评测物种**现学现卖**
   写进了 KB（38 次入库），后半程评测的 BioCLIP 对这些类"开卷考试"。
   → **冷/暖库评测设计原则**：测封闭集能力 → 冻结 KB（v3 冷库 79.9%）；测系统级能力 →
   预载全部评测物种后冻结（v3 暖库 90.5%，离线重打分实现，零 API 成本）。
4. **最终架构结论**：稳态系统（暖库）BioCLIP top1 78.2% / top3 90.5%，显著优于
   qwen-std（McNemar 70:34，p=6e-04）；qwen 的正确定位 = 低分兜底 + OOD 拒答，
   不承担主识别。BioCLIP 相对 qwen 的优势在冷库口径收窄（70:34）但方向与显著性不变。

**评测方法学收获（面试重点）**：
- 评测期间被测系统自己进化（自动入库）会同时污染分数漂移和"开卷考试"两类指标 → 必须能冻结
- 同一系统存在冷/暖两个合法口径，报告必须声明测的是哪个
- 离线重打分（本地模型 + 扩展标签）可以在零 API 成本下补齐暖库口径
